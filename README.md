# CymruEdfryd Ledger

Public records audit of Welsh Government, Senedd and local council spending, waste, asylum-related costs, NGO/charity grants, projects and foreign spending.

**Methodology**: Primary public sources only (Sell2Wales OCDS, StatsWales, Audit Wales, Charity Commission, Companies House, FOI disclosure logs, council accounts). Multi-year growth analysis. Strict verification. No speculation.

**Output**: Structured MD reports → verified quoteable facts → bilingual X drafts for @CymruEdfryd + maps.

**Automation**: Daily Grok research bot + full team (Mapping, Bilingual, Strategist). Human review gate for posting.

**Sources master**: See /sources/

**Verification protocol**: Every figure has primary URL + date + cross-check log. See methodology.md

Built for transparency and accountability for the people of Wales.
