# Verification & Research Methodology

1. Primary source only.
2. Exact quote + URL + retrieval date + archive.
3. Second primary cross-check where possible.
4. Calculations re-verified.
5. Uncertainties noted explicitly.
6. Language: "Public records show..." / "Official figures...". Avoid "fraud" unless Audit Wales/court established.
7. Two-stage check (extract + independent verify).
8. Log in every MD.

Legal: Public data. Fair comment on published numbers. No harassment or ToS violations.
